## 対象 opcode と仕様

### RLA / *RLA (ROL + AND 合成命令)

メモリ値を ROL (左 1 ローテート、C → bit0、bit7 → C) し、その結果で A と AND。
つまり `oldC = C; C = M >> 7; tmp = (M << 1 | oldC) & 0xff; [M] = tmp; A = A & tmp; N/Z フラグ更新` を 1 命令で行う。
C フラグは ROL で設定、N/Z フラグは AND 結果で更新。

nesdev wiki: "RLA: ROL value then AND value"

| opcode | アドレッシング | byte | cycle | nestest 初出行 |
|--------|---------------|------|-------|---------------|
| `23` | (indirect,X) | 2 | 8 | 7411 |
| `27` | zeroPage | 2 | 5 | 7482 |
| `2F` | absolute | 3 | 6 | 7553 |
| `33` | (indirect),Y | 2 | 8 | 7628 |
| `37` | zeroPage,X | 2 | 6 | 7709 |
| `3B` | absolute,Y | 3 | 7 | 7780 |
| `3F` | absolute,X | 3 | 7 | 7861 |

exec ロジック:
```
val = bus.read(op.addr)
const rotated = rolValue(cpu, val)  // C フラグも設定される (oldC → bit0, bit7 → newC)
bus.write(op.addr, rotated)
cpu.a = cpu.a & rotated
cpu.a &= 0xff
setNZ(cpu, cpu.a)  // N/Z フラグを AND 結果で更新
return 0  // RMW 系なので追加 cycle なし
```

## 実装上の注意

- RLA は `name: "*RLA"` (nestest.log 表記)
- RLA は RMW 系: read → modify (ROL) → write → AND。cycle 数に page cross ペナルティはない
- RLA の ROL 部分は `rolValue` ヘルパーを再利用 (C フラグ + ローテート結果を返す)
- RLA の AND 部分: A = A & rotated → N/Z フラグ更新
- 既存 SLO と同じ構造パターンで実装する
- RLA の cycle 数は独自の base cycle (正規 ROL + 正規 AND の合計ではない)
