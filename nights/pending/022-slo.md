## 対象 opcode と仕様

### SLO / *SLO (ASL + ORA 合成命令)

メモリ値を ASL (左 1 シフト、bit7 → C) し、その結果で A と ORA。
つまり `tmp = M << 1; C = M >> 7; [M] = tmp; A = A | tmp; N/Z フラグ更新` を 1 命令で行う。
C フラグは ASL で設定、N/Z フラグは ORA 結果で更新。

nesdev wiki: "SLO: ASL value then ORA value"

| opcode | アドレッシング | byte | cycle | nestest 初出行 |
|--------|---------------|------|-------|---------------|
| `03` | (indirect,X) | 2 | 8 | 6881 |
| `07` | zeroPage | 2 | 5 | 6952 |
| `0F` | absolute | 3 | 6 | 7023 |
| `13` | (indirect),Y | 2 | 8 | 7098 |
| `17` | zeroPage,X | 2 | 6 | 7179 |
| `1B` | absolute,Y | 3 | 7 | 7250 |
| `1F` | absolute,X | 3 | 7 | 7331 |

exec ロジック:
```
val = bus.read(op.addr)
const shifted = aslValue(cpu, val)  // C フラグも設定される
bus.write(op.addr, shifted)
cpu.a = shifted | cpu.a  // ← 注意: ORA は shifted (ASL 結果) と A
// ではなく: A = A | shifted
cpu.a &= 0xff
setNZ(cpu, cpu.a)  // N/Z フラグを ORA 結果で更新
return 0  // RMW 系なので追加 cycle なし
```

## 実装上の注意

- SLO は `name: "*SLO"` (nestest.log 表記)
- SLO は RMW 系: read → modify (ASL) → write → ORA。cycle 数に page cross ペナルティはない
- SLO の ASL 部分は `aslValue` ヘルパーを再利用 (C フラグ + シフト結果を返す)
- SLO の ORA 部分: A = A | shifted → N/Z フラグ更新
- 既存 ISB/DCP と同じ構造パターンで実装する
- SLO の cycle 数は独自の base cycle (正規 ASL + 正規 ORA の合計ではない)
