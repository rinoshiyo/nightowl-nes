Built with Claude Code's autonomous loop: GitHub Flow (Issue → Branch → PR → Review → Merge) running continuously without human intervention.

Human involvement is limited to seeding Issues and morning code reviews.

Constraints

The rules that define this experiment

✓ Allowed References (Oracle)

  • nesdev.org wiki (NES hardware docs)
  • 6502 instruction set specification
  • iNES / NES 2.0 header format

✗ Denied References

All existing NES emulator source code — any language, any license. No peeking, no snippets.

Structurally enforced via pre-tool-use hooks with a deny list.
