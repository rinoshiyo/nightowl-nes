The Self-Driving Loop

Shell scripts and event-driven hooks orchestrate the cycle: worker completes Issue → writes flag → Stop hook fires → loop-helper runs /clear → fresh session picks up next open Issue. Code review runs 7-angle finders under a bot identity. Stuck protocol drafts PRs back after 30 min. Auto-recover restarts from crashes.
